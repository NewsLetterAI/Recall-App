# Recall v1.16

PWA personale per studio, Archivio, ripasso e refertazione.

## Novità v1.16
- toolbar contestuale nell’Archivio: **+ File**, **+ Cartella**, **↻ Sincronizza**;
- caricamento multiplo diretto nella cartella aperta;
- cartelle personalizzate sincronizzate nel repository privato tramite `library/.recall/archive-folders.json`;
- cancellazione sicura delle cartelle personalizzate vuote;
- prompt di continuità `RECALL_PROJECT_BACKUP_PROMPT.md`, copiabile/scaricabile dalle Impostazioni;
- mantiene struttura semplificata per MSK, Pelvi, Urgenze/emergenze e Interventistica;
- mantiene GitHub privato + collegamenti iCloud + PWA offline.

## Repository
Il codice di questa PWA va nel repository pubblico `Recall-App`. I documenti personali restano nel repository GitHub privato configurato dall’utente e/o in iCloud Drive.


## v1.17 — Refertazione Urgenze / emergenze
Aggiunto un percorso dedicato in Refertazione per i casi urgenti derivati dalle mappe **Aneurismi aorta addominale** e **Dissezione aortica**, con 12 casi testuali, random dedicato e controllo dei reperti critici da non perdere.


## v1.17.1 — Scegli su cosa allenarti
Nella sezione Urgenze / emergenze puoi scegliere tutte le urgenze, una singola mappa (Aneurismi aorta addominale o Dissezione aortica), un argomento specifico e avviare un caso casuale limitato alla selezione.


## v1.18 — Traumi addominali in Refertazione Urgenze
Integrata la mappa **Traumi addominali** nel motore di refertazione con 10 nuovi casi testuali urgenti.
Argomenti: trauma splenico con sanguinamento attivo, pseudoaneurisma splenico, trauma epatico con contrast blush, trauma renale con leak urinario, trauma renale vascolare/infarto, rottura vescicale, trauma pancreatico con sospetto danno duttale, trauma intestinale/mesenterico, rottura diaframmatica e trauma addominale multiorgano.
La mappa compare nel selettore **Refertazione → Urgenze / emergenze → Scegli su cosa allenarti** come **TRAUMI ADDOMINALI**, con possibilità di selezionare il singolo argomento o usare il random filtrato.


## v1.19.1 — Ischemia mesenterica acuta
Aggiunti 8 casi testuali in Refertazione → Urgenze / emergenze: embolia AMS, trombosi AMS su ateromasia, occlusione precoce senza segni intestinali, danno avanzato, trombosi venosa mesenterica, NOMI, closed loop con strangolamento e controllo post-rivascolarizzazione.
